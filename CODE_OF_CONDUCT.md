# Code of Conduct

`lai harness` is a technical project for local-first developer tooling. Contributors are expected to keep discussion professional, evidence-based and safe for public collaboration.

## Expected behavior

- Be respectful and precise.
- Critique ideas, code and evidence rather than people.
- Use synthetic examples instead of private user data.
- Disclose security concerns through the security policy, not public issues.
- Respect maintainers' decisions about scope, risk and release timing.

## Unacceptable behavior

- Harassment, threats, personal attacks or discriminatory language.
- Posting credentials, private logs, customer data, proprietary source or other sensitive material.
- Encouraging unsafe execution, credential misuse, unauthorized access or hidden remote effects.
- Repeatedly misrepresenting experimental or planned work as implemented capability.

## Enforcement

Maintainers may edit, hide or remove comments; close issues or pull requests; block participation; or redirect security reports to the private vulnerability process. Enforcement should be proportionate to the risk and documented when practical.
