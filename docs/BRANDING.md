# Branding

The canonical user-facing product name is **lai harness**.

Use **lai harness** in public documentation, extension display names, configuration titles, status text, and release descriptions.

The primary command remains:

```bash
lai
```

The VS Code chat participant remains:

```text
@lai
```

## Compatibility identifiers

The following identifiers are intentionally preserved for compatibility and should not be treated as stale branding:

- `lai` — primary CLI command and chat participant name;
- `local-agent` — installed internal harness executable;
- `lai-local-agent` — current repository URL, extension publisher, and participant namespace;
- `lai-chat` — current VS Code extension package identifier.

Changing compatibility identifiers should be a separate migration with aliases, release notes, and tests.

## Style

Prefer “lai harness” when describing the product and “`lai`” when describing the command. Avoid presenting “LAI — Local AI Agent” as a current product title.
